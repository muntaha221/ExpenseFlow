# ExpenseFlow — Personal Expense Tracker

A small React single-page application for tracking personal expenses.

## Run locally

1. Install dependencies:

```bash
cd c:\Users\Muntaha\Downloads\expenseflow-project\expenseflow
npm install
```

2. Start the dev server:

```bash
npm run dev -- --host 0.0.0.0
```

Open http://localhost:5173/ in your browser.
